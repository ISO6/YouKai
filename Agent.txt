[*]核心工具

3. Naabu: 用于端口发现(与Nmap类似)，但只能扫描端口
4. Httpx: 只关心HTTP和HTTPS(高级Web探针=>状态码，标题，技术栈，页面长度，服务器信息，截图...)
5. Nuclei: 匹配漏洞
6. LLM模型: Qwen3(Qwen3-8B), GPT5, Claude Opus (DeepSeek V4.1 Flash)
7. Chroma: CVE-Chroma存放已知CVE信息以及攻击链路
8. Metasploit指南: https://www.cnblogs.com/wanghaidong/p/19651592
9. Tauri+React+Typescript构建ui

完整工作流:
CVE/Chroma检索 => 资产版本匹配 => Metasploitable模块关联 => LLM生成验证建议
=> 策略引擎检查授权范围 => 人工批准 => 隔离靶场执行验证 => 结果脱敏，入库和生成报告
[*]限制条件:
Agent自主调用: 查询漏洞，搜索匹配模块，读取模块参数和生成验证计划，不执行攻击
人工批准: 高风险工具需审批


多Agent划分:
1. CVE Intelligence Agent: 负责检索 Chroma、解释漏洞和整理证据

2. Asset Matching Agent: 负责产品、版本、平台、补丁状态匹配

3. Validation Planner Agent: 只生成验证方案，不执行

4. Policy Agent: 检查目标范围、模块允许列表和审批状态

5. Lab Executor: 非 LLM 组件，只执行固定、受限操作(连接Metasploit Framework RPC)

6. Report Agent: 将结果写回 Chroma，并生成修复建议
